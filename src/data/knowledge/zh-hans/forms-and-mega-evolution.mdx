## 搜索时要看完整的形态名称

宝可梦猜猜乐把收录的不同形态作为独立答案条目。全国图鉴编号相同，并不代表两个形态是同一个答案。它们的属性、特性、种族值合计和标签可能不同，因此选择搜索结果时需要看完整名称。

## 超级进化是单独的线索

[宝可梦官方介绍](https://mega.pokemon.com/en-us/)将超级进化描述为部分宝可梦能够进行的暂时变化。本游戏的「有超级进化」标签表示当前条目是否具有超级进化资格，不表示普通进化阶段增加一级。

当前游戏数据作了以下区分：

| 条目 | 有超级进化 |
| --- | --- |
| 基格尔德（10%形态） | 否 |
| 基格尔德（50%形态） | 否 |
| 基格尔德（完全体形态） | 是 |
| 普通花叶蒂 | 否 |
| 花叶蒂（永恒之花） | 是 |

## 标签只是一个判断条件

超级进化标签变绿，只能说明答案也具有这个标签，不能说明它们是同一种宝可梦。表格展示的是当前猜测自身的标签；未显示的标签也不能反推出答案的全部标签。结合属性、种族值和具体形态继续排除候选。
