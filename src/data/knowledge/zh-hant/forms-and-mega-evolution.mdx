## 搜尋時要看完整的形態名稱

寶可夢猜猜樂把收錄的不同形態作為獨立答案項目。全國圖鑑編號相同，並不代表兩個形態是同一個答案。它們的屬性、特性、種族值合計和標籤可能不同，因此選擇搜尋結果時需要看完整名稱。

## 超級進化是單獨的線索

[寶可夢官方介紹](https://mega.pokemon.com/en-us/)將超級進化描述為部分寶可夢能夠進行的暫時變化。本遊戲的「有超級進化」標籤表示目前項目是否具有超級進化資格，不表示普通進化階段增加一級。

目前遊戲資料作了以下區分：

| 項目 | 有超級進化 |
| --- | --- |
| 基格爾德（10%形態） | 否 |
| 基格爾德（50%形態） | 否 |
| 基格爾德（完全體形態） | 是 |
| 普通花葉蒂 | 否 |
| 花葉蒂（永恆之花） | 是 |

## 標籤只是一個判斷條件

超級進化標籤變綠，只能說明答案也具有這個標籤，不能說明它們是同一種寶可夢。表格展示的是目前猜測自身的標籤；未顯示的標籤也不能反推出答案的全部標籤。結合屬性、種族值和具體形態繼續排除候選。
