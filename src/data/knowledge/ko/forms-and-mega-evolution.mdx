## 폼을 포함한 전체 이름을 확인하세요

Poke Wordle은 수록된 폼을 각각 별도의 정답 항목으로 취급합니다. 전국도감 번호가 같더라도 두 폼이 같은 정답인 것은 아닙니다. 타입, 특성, 종족값 합계, 태그가 다를 수 있으므로 검색 제안에 표시되는 전체 이름을 확인하세요.

## 메가진화는 별도의 단서입니다

[포켓몬 공식 소개](https://mega.pokemon.com/en-us/ "메가진화에 관한 포켓몬 공식 소개")에서는 메가진화를 일부 포켓몬이 할 수 있는 일시적인 변신으로 설명합니다. 게임의 메가진화 가능 태그는 선택한 항목이 메가진화를 할 수 있는지를 나타냅니다. 일반적인 진화 단계가 하나 더 있다는 뜻은 아닙니다.

현재 Poke Wordle 데이터에서는 다음과 같이 구분합니다.

| 항목 | 메가진화 가능 |
| --- | --- |
| 지가르데 (10%폼) | 불가능 |
| 지가르데 (50%폼) | 불가능 |
| 지가르데 (퍼펙트폼) | 가능 |
| 플라엣테 (일반 모습) | 불가능 |
| 플라엣테 (영원의 꽃) | 가능 |

## 태그는 여러 단서 중 하나로 활용하세요

메가진화 태그가 초록색이면 정답도 그 태그를 갖고 있다는 뜻이지, 같은 종이라는 뜻은 아닙니다. 또한 각 행에는 내가 제출한 포켓몬의 태그가 표시됩니다. 어떤 태그가 없다고 해서 정답이 가질 수 있는 모든 태그를 알 수 있는 것은 아닙니다. 타입, 종족값, 정확한 폼 이름과 함께 비교해 보세요.
