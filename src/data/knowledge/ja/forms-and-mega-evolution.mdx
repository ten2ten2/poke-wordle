## 名前は姿まで確認する

ポケワードルでは、収録されている姿をそれぞれ別の正解候補として扱います。全国図鑑番号が同じでも、別の姿なら同じ答えではありません。タイプ・特性・種族値合計・タグが異なる場合があるので、検索候補の名前を最後まで確認しましょう。

## メガシンカは独立したヒント

[ポケモン公式の紹介](https://mega.pokemon.com/en-us/)では、メガシンカは一部のポケモンが行う一時的な変化とされています。本ゲームのメガシンカのタグは、その項目がメガシンカできるかを表し、通常の進化段階が一段増えるという意味ではありません。

現在のポケワードルのデータでは、次のように区別しています。

| 項目 | メガシンカのタグ |
| --- | --- |
| ジガルデ・10％フォルム | なし |
| ジガルデ・50％フォルム | なし |
| ジガルデ・パーフェクトフォルム | あり |
| 通常のフラエッテ | なし |
| フラエッテ・えいえんのはな | あり |

## 一つのタグだけで決めつけない

メガシンカのタグが緑でも、正解が同じ種類のポケモンとは限りません。また、行に表示されるのは回答したポケモンのタグです。表示されないタグから正解のタグ全体を知ることはできません。タイプや種族値、姿の名前と組み合わせて絞り込みましょう。
