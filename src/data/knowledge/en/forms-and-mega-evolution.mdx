## Check the complete name, including the form

Poke Wordle treats the available forms as separate answer entries. Sharing a National Pokédex number does not make two forms the same answer. Their types, abilities, base stat totals and tags may differ, so use the full name in the search suggestions.

## Mega Evolution is a separate clue

[Pokémon’s official introduction](https://mega.pokemon.com/en-us/) describes Mega Evolution as a temporary transformation available to certain Pokémon. The game’s “Has Mega Evolution” tag records whether the selected entry can access it; it is not an extra ordinary evolution stage.

The current Poke Wordle dataset makes these distinctions:

| Entry | Has Mega Evolution |
| --- | --- |
| Zygarde 10% Forme | No |
| Zygarde 50% Forme | No |
| Zygarde Complete Forme | Yes |
| Ordinary Floette | No |
| Eternal Flower Floette | Yes |

## Use a tag as one piece of evidence

A green Mega Evolution tag means the answer shares that tag, not that it is the same species. Also, rows show the tags of your guess: an absent tag does not reveal every tag the answer might have. Combine this clue with types, stats and the exact form name.
