## A generation is a filter, not a Pokédex number

Settings currently offers Gen 1 through Gen 9. Selecting generations limits both the possible answer and the Pokémon available for guesses. At least one generation must remain selected. Searching by a National Pokédex number does not override this filter.

The game uses the generation assigned to each entry in its dataset. Regional forms can differ from their original species: for example, ordinary Vulpix belongs to Gen 1 here, while Alolan Vulpix belongs to Gen 7. A Pokémon appearing in a newer game does not automatically move to that game’s generation.

## Which settings start a new round?

Changing the selected generations, guess limit, Prankster mode or generation arrows clears the current round. Choose these options before submitting your first guess if you want to keep a consistent challenge.

Changing guess display order only rearranges the existing rows. It does not change the answer or erase your guesses. Reverse order puts the newest guess first; normal order puts it last.

## Replaying and saved progress

Restart clears the round; the next valid guess starts a new one with a randomly chosen answer. Giving up reveals the answer and ends the round. Progress is saved in the current browser, so clearing browser storage also clears saved progress.
