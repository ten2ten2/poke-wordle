## Start with the value shown on your guess

Each row describes the Pokémon you submitted. A green tag means that value matches the answer; a gray tag means it differs. Type, ability and special tags are checked individually, so a green type does not prove that the entire type combination matches.

## What counts as a close match?

| Clue | Green | Yellow |
| --- | --- | --- |
| Base stat total | Same total | Different by 50 or less |
| Generation | Same generation | One generation apart |
| Evolution method | Same method and detail | Same method category, different detail |

Evolution stage is a separate comparison. Its tag turns green only when the stage matches. The values shown here are this game’s comparison rules.

## Which way do the arrows point?

An up arrow means the answer’s value is higher than your guess; a down arrow means it is lower. For a guess with a base stat total of 500, a yellow up arrow puts the answer between 501 and 550. Generation arrows appear only when enabled in Settings.

## Why can a guess with green clues still be wrong?

Winning requires the exact Pokémon entry, including its form. Several entries can share the same attributes. In Prankster mode, one column is hidden on an incorrect guess; a hidden clue provides no evidence either way.
