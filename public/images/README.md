# SEO Images Directory

This directory should contain the following images for optimal SEO:

## Required Images

### Open Graph & Social Media
- `og-image.png` (1200x630px) - Main Open Graph image for social media sharing
- `twitter-image.png` (1200x630px) - Twitter card image
- `apple-touch-icon.png` (180x180px) - Apple touch icon for iOS devices

### PWA Icons
- `icon-96x96.png` (96x96px)
- `icon-192x192.png` (192x192px)
- `icon-512x512.png` (512x512px)

### PWA Screenshots
- `screenshot-wide.png` (1280x720px) - Desktop screenshot
- `screenshot-narrow.png` (390x844px) - Mobile screenshot

## Image Guidelines

1. **Format**: Use PNG for icons and logos, WebP for photos when possible
2. **Optimization**: Compress images for web without losing quality
3. **Alt Text**: All images should have descriptive alt text in the code
4. **Branding**: Use consistent colors and branding across all images
5. **Content**: Images should represent the Poke Wordle game clearly

## Tools for Image Creation

- **Design**: Figma, Canva, or Adobe Creative Suite
- **Optimization**: TinyPNG, ImageOptim, or Squoosh
- **Icon Generation**: PWA Builder, RealFaviconGenerator

## Notes

- The manifest.json file references these images
- Open Graph images are used by social media platforms
- PWA icons enable the app to be installed on devices
- Screenshots help users understand the app before installing
