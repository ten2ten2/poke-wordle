# 宝可梦数据工具

从 PokeAPI 生成游戏主数据、九语言名称和恶作剧模式图片。工具链由根目录 `mise.toml` 固定。

在仓库根目录运行：

```sh
mise run data:console
```

打开 http://127.0.0.1:3318。点击“检查上游更新”生成隔离候选并自动校验，再对照 `src/data/` 查看旧值、新值、图片与来源证据。逐项接受或记录修正意见；所有待确认项接受后，“应用并运行检查”同步数据并执行完整检查及游戏 E2E。历史批次只供查看。

审核意见绑定报告版本；“保留原值”“要求修正”“暂缓”会阻止整批应用，需要修正生成规则并重建。应用时核验来源、基准、候选、报告和审核记录，同步稳定 ID 与数据版本。不会自动提交或推送。

`mise run data:check` 包含 Go 静态/竞态检查、流程回归和发布数据校验；`mise run data:verify` 只校验已发布数据。两个命令均不访问上游。

`mise run data:console:test` 用临时数据运行桌面和手机浏览器回归。首次运行需执行 `mise exec -- npm exec -- playwright install chromium`。

直接在工具目录运行 `go run .` 仍提供历史交互导出/比较功能，其 `output/`、`backup/` 和分类翻译只供临时用途，不能用作发布基准。正式更新统一使用上面的批次命令。
